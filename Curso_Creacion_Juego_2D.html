Tutorial Instrucción por Instrucción

Crea tu Plataformero 2D desde Cero

Cada paso te dice exactamente qué menú abrir, dónde hacer clic, qué arrastrar y qué valor escribir. No se asume nada. Síguelo como receta de cocina.

01

Crear el Proyecto en Unity Hub

Desde cero, sin nada abierto

Instrucciones exactas:

Abre Unity Hub (el lanzador azul de Unity, no el editor).
En la barra lateral izquierda, haz clic en Projects.
Arriba a la derecha, haz clic en el botón azul New Project.
En la lista de plantillas del lado izquierdo, selecciona 2D (URP) — es la que tiene un ícono de un cuadrado con colores.
En el campo Project Name (arriba a la derecha) escribe: Prueba-1
En Location, haz clic en los tres puntos ... y navega hasta tu carpeta de la materia.
Haz clic en el botón azul Create Project. Espera 2-5 minutos a que Unity cargue.
💡
Cuando termine de cargar verás el editor de Unity con una escena vacía llamada SampleScene. Esa es tu área de trabajo.
02

Importar los Sprites del Personaje

Meter las imágenes dentro de Unity

Traer la imagen Player.png al proyecto:

En Unity, mira la ventana de abajo llamada Project. Ahí ves la carpeta Assets.
Haz clic derecho en el espacio vacío dentro de Assets ➜ selecciona Create ➜ Folder. Nómbrala Sprites.
Haz doble clic en la carpeta Sprites para entrar en ella.
Ahora abre el Explorador de Archivos de Windows (tecla Windows + E). Navega hasta donde tengas tu imagen Player.png (la hoja de sprites del personaje).
Arrastra el archivo Player.png desde el Explorador de Windows directamente hacia la ventana Project de Unity, dentro de la carpeta Sprites.
Espera un par de segundos. Verás que aparece un ícono de imagen dentro de la carpeta. ¡Ya está importada!
⚠️
¿No tienes imagen? Si estás usando el paquete Pixel Adventure 1, ya incluye personajes. Puedes usarlos desde Assets ➜ Pixel Adventure 1 ➜ Assets ➜ Main Characters.
03

Configurar Sprites para Pixel Art Nítido

Eliminar el desenfoque y los píxeles borrosos

¿Por qué se ven borrosos los sprites?

Porque Unity usa un filtro "Bilinear" que suaviza los bordes. Para pixel art necesitas "Point" que muestra cada píxel tal cual, nítido y cuadrado.

Instrucciones exactas para CADA imagen:

En la ventana Project, navega a la carpeta Sprites.
Haz un solo clic sobre el archivo Player.png (NO doble clic, solo un clic para seleccionarlo).
Mira la ventana Inspector del lado derecho. Ahí aparecen las propiedades de la imagen.
Busca el campo Texture Type. Confirma que diga Sprite (2D and UI). Si no, cámbialo con el menú desplegable.
Busca el campo Sprite Mode. Si tu imagen tiene VARIOS personajes o frames en una sola hoja, cámbialo a Multiple.
Busca el campo Pixels Per Unit. Déjalo en 100.
Busca el campo Filter Mode. Haz clic en el menú desplegable y cámbialo de Bilinear a Point (no filter).
Busca el campo Compression. Cámbialo a None.
Haz clic en el botón Apply que está abajo a la derecha del Inspector. Es un botón que dice "Apply". Si no lo presionas, los cambios no se guardan.

04

Recortar el Sprite Sheet en el Sprite Editor

Separar cada frame de animación individual

¿Por qué recortar?

Tu archivo Player.png es una sola imagen con TODOS los frames del personaje (caminando arriba, abajo, izquierda, derecha). Necesitas decirle a Unity dónde empieza y termina cada frame.

Selecciona Player.png con un clic en la ventana Project.
En el Inspector (derecha), busca el botón que dice Sprite Editor. Haz clic en él. Se abrirá una ventana nueva.
En la esquina superior izquierda de la ventana Sprite Editor, haz clic en el botón Slice (tiene ícono de tijeras).
Se abrirá un menú desplegable. Configúralo así:
• Type: selecciona Grid By Cell Size
• Pixel Size X: escribe 20 (o el ancho de cada frame de tu personaje)
• Pixel Size Y: escribe 28 (o el alto de cada frame)
Haz clic en el botón Slice dentro de ese menú desplegable. Verás que aparecen rectángulos azules sobre cada frame del personaje.
Verifica visualmente que cada rectángulo azul encierre UN solo frame. Si alguno corta mal, puedes arrastar las esquinas para ajustarlo.
Arriba a la derecha de la ventana Sprite Editor, haz clic en Apply.
Cierra la ventana del Sprite Editor (la X de esa ventana).
Ahora, en la ventana Project, haz clic en la flechita ▶ a la izquierda de Player.png. Deberías ver todos los sprites individuales: Player_0, Player_1, Player_2, etc.
✅
¡Ya tienes cada frame individual! Ahora podrás usarlos para crear animaciones.
05

Crear la Paleta de Tiles para el Escenario

Preparar las baldosas del piso

Instrucciones exactas:

En el menú superior de Unity, haz clic en Window ➜ 2D ➜ Tile Palette. Se abrirá una ventana flotante.
En la ventana Tile Palette, haz clic en el botón Create New Palette.
En el campo Name escribe: Terreno.
Deja Grid en Rectangle y Cell Size en Automatic.
Haz clic en Create. Te pedirá dónde guardarla. Crea una carpeta llamada Paleta dentro de Assets y guárdala ahí.
Ahora, en la ventana Project, navega hasta tu imagen de terreno. Si usas Pixel Adventure 1, está en:
Assets ➜ Pixel Adventure 1 ➜ Assets ➜ Terrain ➜ Terrain Sliced (16x16).png
Arrastra esa imagen completa desde la ventana Project y suéltala dentro de la ventana Tile Palette (en el cuadro gris).
Te pedirá dónde guardar los Tiles. Crea una carpeta Tiles dentro de Assets y guárdalos ahí. Espera unos segundos.
¡Ahora verás todas las baldosas del terreno en la paleta! Puedes hacer scroll para ver más.
06

Pintar el Escenario con el Tilemap

Dibujar el piso y las plataformas

Crear el Tilemap (el lienzo para pintar):

En la ventana Hierarchy (izquierda), haz clic derecho en un espacio vacío.
Selecciona 2D Object ➜ Tilemap ➜ Rectangular.
Se creará un objeto llamado Grid con un hijo llamado Tilemap. Renombra el hijo: haz clic derecho sobre "Tilemap" ➜ Rename ➜ escribe Piso.

Ajustar el tamaño de celda del Grid:

Haz un clic sobre el objeto Grid en la Hierarchy.
En el Inspector (derecha), busca el componente Grid.
En Cell Size, cambia los valores a: X = 0.16 , Y = 0.16 , Z = 0.
💡
¿Por qué 0.16? Porque tus baldosas miden 16 píxeles y el PPU es 100. Entonces: 16 ÷ 100 = 0.16 unidades de Unity por baldosa.

Pintar el suelo con la brocha:

Abre la ventana Tile Palette (si la cerraste: Window ➜ 2D ➜ Tile Palette).
En la paleta, haz clic en la baldosa de terreno que quieras usar (ej. una baldosa verde con pasto).
Asegúrate de que la herramienta seleccionada sea el Pincel (ícono de brocha, es la primera herramienta en la barra de la Tile Palette).
Asegúrate de que abajo en la paleta, en Active Tilemap, diga Piso.
Ahora ve a la ventana Scene (la vista principal del editor) y haz clic y arrastra para pintar baldosas en línea horizontal. Pinta una fila larga como suelo.
Puedes agregar plataformas más arriba pintando bloques sueltos en el aire para que el jugador salte entre ellos.
07

Agregar Colisión Sólida al Suelo

Para que el jugador no atraviese el piso

Sin esto, el personaje cae al vacío infinito:

En la Hierarchy, haz clic en el objeto Piso (el hijo de Grid).
En el Inspector (derecha), baja hasta el final y haz clic en Add Component.
En el buscador que aparece, escribe Tilemap Collider 2D y selecciónalo de la lista.
Ahora en el componente que se agregó, busca la casilla Used By Composite y márcala (haz clic en el checkbox).
Haz clic otra vez en Add Component. Escribe Composite Collider 2D y selecciónalo.
Esto creará automáticamente un componente Rigidbody2D también. Búscalo en el Inspector.
En el Rigidbody2D del Piso, cambia Body Type de Dynamic a Static.
🔴
¡IMPORTANTÍSIMO! Si no cambias el Body Type a Static, ¡el suelo se caerá por gravedad cuando le des Play! El piso debe ser estático porque no se mueve.

08

Crear el GameObject del Jugador

Poner al personaje en la escena
En la ventana Project, navega a la carpeta Sprites.
Haz clic en la flechita ▶ de Player.png para expandir los sub-sprites.
Arrastra el primer sprite (ej. Player_0) desde la ventana Project hacia la ventana Scene (la vista central).
Se creará un objeto en la Hierarchy. Renómbralo: haz clic derecho ➜ Rename ➜ escribe Player.
Con el objeto Player seleccionado, mira el Inspector. Busca el campo Tag (arriba, debajo del nombre). Haz clic en el desplegable y selecciona Player.
⚠️
¿No aparece "Player" en la lista de Tags? Haz clic en Add Tag..., luego en el + de Tags, escribe Player y haz clic en Save. Después regresa al objeto y selecciona el tag recién creado.
Usa la herramienta Move (tecla W) para posicionar al personaje arriba del suelo que pintaste. Que sus pies estén justo encima de las baldosas.

Darle física y cuerpo sólido al personaje

Agregar componentes de física:

Haz clic en el objeto Player en la Hierarchy.
En el Inspector, baja y haz clic en Add Component.
Escribe Rigidbody 2D en el buscador y selecciónalo.
En el componente Rigidbody 2D que se agregó, configura:
• Mass: cambia de 1 a 1 (déjalo en 1)
• Gravity Scale: cambia a 2.5

10

Calibrar la Cámara para que se vea bien

Solucionar el problema de "todo se ve diminuto"

¿Por qué se ve todo tan pequeño?

La cámara tiene un "tamaño ortográfico" demasiado grande (por defecto es 5). Esto significa que está mostrando demasiado espacio del mundo, haciendo que los sprites de 16 píxeles se vean como hormigas.

Instrucciones exactas:

En la Hierarchy, haz clic en el objeto Main Camera.
En el Inspector, busca el componente Camera.
Confirma que Projection diga Orthographic (si dice Perspective, cámbialo).
Busca el campo Size (o "Orthographic Size"). Cambia el número de 5 a 1.35.
Ahora busca Clear Flags (o "Background Type"). Cámbialo a Solid Color.
Haz clic en el cuadro de color de Background y selecciona un azul cielo claro (ej. R:107, G:189, B:249).
Usa la herramienta Move (tecla W) para mover la cámara hasta que el personaje esté centrado en la vista previa (el rectángulo de la cámara que ves en la Scene).

Crear las Animaciones del Personaje

Idle, caminar este, caminar oeste

Crear la animación de reposo (Idle):

En la ventana Project, haz clic derecho ➜ Create ➜ Folder. Nómbrala Animaciones.
Abre la ventana Animation: menú superior ➜ Window ➜ Animation ➜ Animation.
Haz clic en el objeto Player en la Hierarchy.
En la ventana Animation, haz clic en Create. Te pedirá dónde guardar. Navega a la carpeta Animaciones, nombra el archivo como player_descansando y haz clic en Save.
Ahora en la ventana Project, expande Player.png (haz clic en la flechita ▶).
Selecciona los sprites que representan al personaje en reposo (ej. el que mira al frente, quieto). Puedes seleccionar varios manteniendo Ctrl presionado mientras haces clic.
Arrastra esos sprites seleccionados hacia la línea de tiempo de la ventana Animation (el área con las líneas verticales).

Crear las animaciones de caminata:

En la ventana Animation, haz clic en el menú desplegable que dice player_descansando (arriba a la izquierda de la línea de tiempo).
Selecciona Create New Clip...
Guárdalo en la carpeta Animaciones con el nombre player_este. Haz clic en Save.
Arrastra los sprites del personaje caminando hacia la derecha a la línea de tiempo (igual que antes).
Repite los pasos 8-11 para crear player_oeste (caminando izquierda), player_norte (caminando arriba) y player_sur (caminando abajo).
💡
Cada vez que creas un clip nuevo, Unity lo agrega automáticamente al Animator Controller del personaje (un archivo que se creó en la carpeta Animaciones llamado Player.controller o similar).

Configurar el Animator Controller (Máquina de Estados)

Decirle a Unity cuándo reproducir cada animación

Abrir el Animator:

En la ventana Project, busca en la carpeta Controladores (o Animaciones) el archivo Player.controller (tiene ícono de diagrama de flujo).
Haz doble clic sobre Player.controller. Se abrirá la ventana Animator mostrando cajas de colores conectadas con flechas.

Crear los parámetros:

En la ventana Animator, busca la pestaña Parameters en el panel izquierdo. Haz clic en ella.
Haz clic en el botón + (al lado de la barra de búsqueda de parámetros).
Selecciona Float. Aparecerá un parámetro nuevo. Escribe x como nombre y presiona Enter.
Haz clic en + otra vez ➜ Float. Nómbralo y.
Haz clic en + otra vez ➜ Bool. Nómbralo descansando. Marca su checkbox (que su valor por defecto sea true).

Establecer el estado predeterminado:

Haz clic derecho sobre la caja naranja (o sobre la caja player_descansando) y selecciona Set as Layer Default State. La caja se pondrá naranja. Esto significa que el juego empezará en esta animación.

Crear las transiciones desde "Any State":

Haz clic derecho sobre la caja verde que dice Any State.
Selecciona Make Transition. Aparecerá una flecha blanca siguiendo tu ratón.
Haz clic sobre la caja player_este. La flecha se conectará.
Ahora haz clic sobre esa flecha blanca que acabas de crear (la línea entre Any State y player_este).
En el Inspector (derecha), configura la transición:
• Has Exit Time: DESMARCA esta casilla
• Transition Duration (%): escribe 0
• Can Transition To Self: DESMARCA esta casilla
Baja hasta la sección Conditions. Haz clic en el botón +.
Configura la condición: x — Greater — 0.1

13

Configurar el New Input System

Las teclas WASD y Espacio

Instalar el paquete (si no está):

Menú superior ➜ Window ➜ Package Manager.
Arriba a la izquierda, cambia el desplegable de Packages: In Project a Unity Registry.
En la barra de búsqueda, escribe Input System.
Selecciónalo de la lista y haz clic en Install. Si ya dice "Up to date", ya lo tienes.
Unity te pedirá reiniciar. Haz clic en Yes.

Crear el archivo de Controles:

En la ventana Project, navega a la carpeta Scripts (si no existe, créala: clic derecho ➜ Create ➜ Folder ➜ "Scripts").
Haz clic derecho dentro de la carpeta Scripts ➜ Create ➜ Input Actions.
Nómbralo ControlesPlayer y presiona Enter.
Doble clic sobre ControlesPlayer para abrirlo. Se abre una ventana de edición de acciones.

Configurar las acciones:

En el panel Action Maps (izquierda), haz clic en + para crear un mapa. Nómbralo Player.
En el panel Actions (centro), haz clic en + para crear una acción. Nómbrala Move.
Con "Move" seleccionada, en el panel Properties (derecha), cambia Action Type a Value y Control Type a Vector2.
Haz clic en el + al lado de "Move" ➜ selecciona Add Up/Down/Left/Right Composite. Se crearán 4 bindings.
Haz clic en Up. En Properties ➜ Path, haz clic y busca W [Keyboard].
Haz clic en Down ➜ Path ➜ S [Keyboard].
Haz clic en Left ➜ Path ➜ A [Keyboard].
Haz clic en Right ➜ Path ➜ D [Keyboard].
Opcionalmente repite 13-17 para agregar las flechas del teclado también.
Crea otra acción con +. Nómbrala Jump. Action Type: Button.
Haz clic en <No Binding> debajo de Jump. En Properties ➜ Path, selecciona Space [Keyboard].
Guarda con Ctrl + S.

Generar la clase C#:

Cierra la ventana del editor de Input Actions.
En la ventana Project, haz un solo clic sobre ControlesPlayer para seleccionarlo.
En el Inspector, busca la casilla Generate C# Class y márcala.
Haz clic en Apply. Esto genera un archivo ControlesPlayer.cs automáticamente. ¡No lo edites manualmente!
14

Crear el Script MovePlayer.cs

El cerebro del personaje

Crear el archivo de script:

En la ventana Project, navega a la carpeta Scripts.
Haz clic derecho ➜ Create ➜ C# Script.
Inmediatamente (antes de hacer clic en otro lado) escribe MovePlayer como nombre y presiona Enter.
Doble clic sobre MovePlayer.cs para abrirlo en Visual Studio.
Borra todo el contenido del archivo y pega el siguiente código completo:
MovePlayer.cs — Copiar y Pegar COMPLETO
using UnityEngine;
using UnityEngine.InputSystem;

[RequireComponent(typeof(Rigidbody2D))]
public class MovePlayer : MonoBehaviour
{
    [Header("Ajustes de Movimiento")]
    public float velocidad = 2.2f;
    public float salto = 6.2f;

    [Header("Detección de Suelo")]
    public LayerMask capaSuelo;

    private ControlesPlayer controlPlayer;
    private Vector2 movimiento;
    private Rigidbody2D rb;
    private Animator animator;
    private Collider2D col;
    private float tiempoUltimoSalto = 0f;

    void Awake()
    {
        controlPlayer = new ControlesPlayer();
        rb = GetComponent<Rigidbody2D>();
        animator = GetComponent<Animator>();
        col = GetComponent<Collider2D>();

        if (rb != null)
            rb.constraints = RigidbodyConstraints2D.FreezeRotation;
    }

    void Update()
    {
        if (controlPlayer != null)
        {
            movimiento = controlPlayer.Player.Move.ReadValue<Vector2>();
            cambioEstado();
        }
    }

    void FixedUpdate()
    {
        if (rb != null)
        {
            // Horizontal: input × velocidad
            // Vertical: conservar la velocidad Y (gravedad y salto)
            rb.linearVelocity = new Vector2(
                movimiento.x * velocidad,
                rb.linearVelocity.y
            );
        }
    }

    private void cambioEstado()
    {
        if (animator == null) return;

        bool caminando = Mathf.Abs(movimiento.x) > 0.05f;
        animator.SetFloat("x", movimiento.x);
        animator.SetFloat("y", 0f);
        animator.SetBool("descansando", !caminando);
    }

    private void OnJump(InputAction.CallbackContext context)
    {
        Jump();
    }

    public void Jump()
    {
        if (rb == null) return;
        if (Time.time - tiempoUltimoSalto < 0.2f) return;

        if (EstaEnPiso())
        {
            rb.linearVelocity = new Vector2(rb.linearVelocity.x, salto);
            tiempoUltimoSalto = Time.time;
            ChecaColision.isPiso = false;
        }
    }

    public bool EstaEnPiso()
    {
        if (ChecaColision.isPiso) return true;

        if (col != null)
        {
            Bounds b = col.bounds;
            Vector2 pies = new Vector2(b.center.x, b.min.y);
            Vector2 sensor = new Vector2(b.size.x * 0.85f, 0.05f);
            int capa = capaSuelo.value != 0
                ? capaSuelo.value
                : ~LayerMask.GetMask("Ignore Raycast");
            Collider2D hit = Physics2D.OverlapBox(pies, sensor, 0f, capa);
            if (hit != null && hit.gameObject != gameObject && !hit.isTrigger)
                return true;
        }
        return false;
    }

    void OnEnable()
    {
        if (controlPlayer == null)
            controlPlayer = new ControlesPlayer();
        controlPlayer.Enable();
        controlPlayer.Player.Jump.performed += OnJump;
    }

    void OnDisable()
    {
        if (controlPlayer != null)
        {
            controlPlayer.Player.Jump.performed -= OnJump;
            controlPlayer.Disable();
        }
    }

    void OnDestroy()
    {
        controlPlayer?.Dispose();
    }
}
Guarda el archivo con Ctrl + S y regresa a Unity. Espera a que compile (barra de progreso abajo).

Crear el Script ChecaColision.cs

El sensor que impide el doble salto en el aire
En la ventana Project, carpeta Scripts, haz clic derecho ➜ Create ➜ C# Script.
Nómbralo ChecaColision y presiona Enter.
Doble clic para abrir. Borra todo y pega:
ChecaColision.cs — Copiar y Pegar COMPLETO
using System.Collections;
using System.Collections.Generic;
using UnityEngine;

public class ChecaColision : MonoBehaviour
{
    public static bool isPiso = false;

    private void OnTriggerEnter2D(Collider2D collision)
    {
        if (collision.CompareTag("Player")) return;
        Debug.Log("En Piso");
        isPiso = true;
    }

    private void OnTriggerStay2D(Collider2D collision)
    {
        if (collision.CompareTag("Player")) return;
        isPiso = true;
    }

    private void OnTriggerExit2D(Collider2D collision)
    {
        if (collision.CompareTag("Player")) return;
        Debug.Log("No En Piso");
        isPiso = false;
    }
}
Guarda con Ctrl + S y regresa a Unity.
