# unity-2d-basics

Práctica introductoria de mecánicas y controladores en **Unity 2D**, correspondiente a la Unidad 1 de la materia de Creación de Videojuegos.

## Características
- Implementación del nuevo sistema de entrada (*Unity Input System*).
- Control de movimiento del jugador (`MovePlayer.cs`, `ControlesPlayer.cs`).
- Seguimiento suave de cámara (`CameraFollow.cs`).
- Detección de colisiones (`ChecaColision.cs`).
- Tilemaps y paletas de tiles 2D (*Pixel Adventure 1*).

## Requisitos
- Unity 6 / Unity 2022 LTS o superior.
- Paquetes: *Input System*, *2D Tilemap Editor*.
